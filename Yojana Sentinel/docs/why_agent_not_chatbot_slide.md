# Why Agent, Not Chatbot? (Slide Content)

## Yojana Sentinel vs. One-Shot Welfare Tools (Yojana Matcher / Am I Eligible)

| Dimension | One-Shot Q&A Tools / Chatbots | Yojana Sentinel (Agentic Pipeline) |
|---|---|---|
| **Vigilance** | Single lookup — forgets citizen immediately after answering. | **Monitors continuously** — detects portal updates and deadline changes 24/7. |
| **Actionability** | Returns static list of scheme names; user does all the work. | **Acts & Drafts** — pre-fills application fields and generates cover notes. |
| **Follow-through** | Zero post-search awareness. | **Tracks & Nudges** — alerts family members when applications stall past threshold days. |
| **Trust Model** | Generates text answers via raw LLM (risk of hallucination). | **Hybrid Determinism** — 7-rule hard engine for criteria + LLM restricted to free-text review. |
| **Submission Safety** | N/A (informational only). | **Strict Human-in-the-Loop** — prepares drafts; human always approves and manually submits. |
